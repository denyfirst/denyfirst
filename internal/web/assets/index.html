Check what a server
actually negotiates.

Not what it advertises. This opens a real handshake at every TLS version, works out which cipher suites the server will accept, and reads the certificate chain it presents.

Port 443 unless you name another. Public hosts only. Scan only what you are entitled to scan — see the terms.

The hostname travels in the request body, never in the address bar, so it stays out of your history and out of every proxy log on the way here. Nothing about the scan is written down at this end either.
