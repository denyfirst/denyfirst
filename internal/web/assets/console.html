This installation

Scope
{{if .Verified}}Only domains this installation has been shown control of. A name nobody proved anything about is refused before anything is dialled.{{else}}No proof of control is required. This installation will scan any public name it is given. That is the right setting for a machine only you can reach, and the wrong one for anything a stranger can. See what a scan does.{{end}}
Pages
{{if .ReadsPages}}Read, where control was proven — once, to a bound of one megabyte, and nothing of the page is kept beyond a short list of facts.{{else}}Not read. Without a proof of control this installation takes headers only, so mixed content and a policy declared in the markup are not established either way.{{end}}
Results
{{if .Keeps}}Kept on this machine, because this installation was told to keep them: the date, the verdict and which rules were raised, per target and per check. Nothing is served back — read them with porch-scan -history, which makes no connection. Nothing about who asked is written down, here or anywhere.{{else}}Not kept. Nothing about a scan is written to disk: not the name, not the verdict, not the time. Close this page and the report is gone — save the JSON from the report itself if you want to keep it, or start this installation with -results-dir.{{end}}
Rule sets
{{range .Checks}}{{.Policy}}{{end}} Each check has its own, and they move independently. A report carries the one that graded it, because a verdict from one means nothing under another.
